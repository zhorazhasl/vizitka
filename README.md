# Визитка — Хажидулла Жасулан Еркинулы

Простая страница-визитка: имя, профессия (инженер-геолог) и кнопка «Написать мне», которая открывает чат в Telegram ([@zhaslzhora](https://t.me/zhaslzhora)).

## Как открыть

Страница состоит из одного файла `index.html` и не требует сборки или установки зависимостей.

- Дважды щёлкните `index.html`, и он откроется в браузере.
- Или из PowerShell: `Start-Process index.html`

## Что внутри

- `index.html` — разметка и стили в одном файле.
- Тёмная тема, фиолетовая кнопка, вёрстка подстраивается под экран телефона.

## Как поменять данные

- Имя, профессия и инициалы в кружке находятся в блоке `<main class="card">`.
- Ссылка кнопки задаётся в атрибуте `href` у элемента с классом `button`.
- Цвета задаются в блоке `<style>` в начале файла.
